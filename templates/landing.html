// why this exists

Built because Canvas was in the way.

I'm a student at Vinschool. Every week meant opening Canvas, clicking a course, scrolling a module list, and hoping the quiz I needed was where I remembered it. It usually wasn't.

So I built VinFocus. It reads the same courses you already have and rearranges them into weeks, a search bar, and a progress view. It doesn't decide what you should do. It makes what exists easier to find.

not affiliated with vinschool or canvas. it just makes them usable.

// privacy

Check the permissions yourself.

No signup. No account. No server-side storage of anything that matters.

$ vinfocus --check-permissions
READ courses yes
READ assignments yes
WRITE anything no
SUBMIT assignments no
STORE token browser only
SEND your data nowhere

Your Access Card lives in your browser and goes straight to Canvas. It is never stored on VinFocus servers, and nothing is collected or shared.

Frequently asked questions

Quick answers to common questions.

No. VinFocus is an independent project created by a student. It is not affiliated with Vinschool or Canvas LMS. It uses Canvas's public API to read course data with your permission.

VinFocus uses Canvas's API to fetch your course data. The API requires an access token (Access Card) to authenticate you. The token is never stored on our servers.

Yes. Your token is stored only in your browser's localStorage or sessionStorage. It is sent directly to Canvas with each request and is never logged or stored on VinFocus servers. No data is collected or shared.

No. VinFocus uses the same Canvas API that any student can use. It makes read-only requests that are indistinguishable from normal Canvas usage. There is no way for teachers to detect VinFocus.

VinFocus isn't a replacement — it's a faster, read-only window onto the same Canvas data you already use. Because it reads straight from Canvas, there's no second account, no migration, and nothing new to manage. It just saves the clicks.
